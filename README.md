# BRU VANS Locadora

Site institucional da BRU VANS — locação de vans, micro-ônibus e ônibus.

## Desenvolvimento

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## SEO / domínio

Antes de publicar, substitua `https://bruvans.com.br` pelo domínio real em:

- `index.html` (canonical, Open Graph, Twitter e JSON-LD)
- `public/robots.txt`
- `public/sitemap.xml`

Depois do deploy, envie o sitemap no [Google Search Console](https://search.google.com/search-console).
